# Duroflex (duroflexworld.com)

> Duroflex is India's trusted sleep-solutions brand, selling mattresses, sofas,
> recliners, beds, pillows and protectors direct-to-consumer. The store runs on
> Shopify and exposes agent-facing commerce surfaces: a hosted Storefront MCP
> server for catalog/cart/policy operations and a Shopify Customer Account API
> (OAuth 2.0 / OpenID Connect) for authenticated customer operations. This
> llms.txt is generated by the API Evangelist enrichment pipeline from the store's
> public discovery surfaces; there is no first-party developer API program beyond
> the Shopify platform.

## Agent surfaces
- Storefront MCP server (HTTP): https://www.duroflexworld.com/api/mcp — tools: search_catalog, get_cart, update_cart, get_product_details, search_shop_policies_and_faqs
- OpenID Connect discovery: https://duroflexworld.com/.well-known/openid-configuration
- OAuth authorization-server metadata: https://duroflexworld.com/.well-known/oauth-authorization-server

## Auth
- Shopify Customer Account API — OAuth 2.0 authorization-code + PKCE (S256), OIDC
- Authorization: https://account.duroflexworld.com/authentication/oauth/authorize
- Token: https://account.duroflexworld.com/authentication/oauth/token
- Scopes: openid, email, customer-account-api:full, customer-account-mcp-api:full
